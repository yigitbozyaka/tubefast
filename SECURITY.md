# Security

Tubefast stores a signed-in YouTube session on your computer, encrypted with your Windows account on Windows and readable only by your user on macOS and Linux. Problems in how that session is obtained, stored or sent are treated as security issues, as is anything that lets a remote party run code or read files.

## Reporting

Please do not open a public issue. Use **Report a vulnerability** under the repository's Security tab:

https://github.com/yigitbozyaka/tubefast/security/advisories/new

Include what you found, how to reproduce it and which version you used. You will get a reply as soon as possible, and credit in the release notes if you want it.

## Supported versions

Only the latest release receives fixes.
